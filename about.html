About Fast Mode

Understand your connection, one measurement at a time.

Fast Mode is a free browser-based network toolkit for checking download and upload throughput, latency, jitter, loaded latency, estimated packet loss and public DNS response time.

Run a test without creating an account or installing an app. Results are estimates of how this device and browser reach the selected test services at the time you run them.

How the speed test works

The test sends real network requests to third-party test endpoints. It measures repeated latency samples, then measures download and upload throughput with parallel requests. It also checks latency while the connection is busy. The values can vary with Wi-Fi conditions, device performance, browser behavior, VPNs, congestion and the route to the test server.

What the DNS benchmark measures

The DNS benchmark sends DNS-over-HTTPS queries to selected public resolvers and compares the response times visible from your browser. It is not a direct measurement of plain DNS over UDP, your operating system’s resolver, or the DNS configuration used by every app.

Privacy by design

Test history and display preferences are saved in local browser storage on this device. Fast Mode does not upload those saved results to its own server. The browser does contact the third-party test, IP lookup and DNS providers described in the Privacy Policy.
