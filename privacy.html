Privacy Policy

Last updated: October 24, 2026. This page explains the data flows in the current Fast Mode website.

Information saved on your device

Fast Mode does not require an account. Test history (up to 25 results), the speed unit preference and the theme preference are stored in this browser’s local storage. They are not sent to a Fast Mode account or results database. Use the Clear button in Test History to remove saved results, or clear this site’s browser storage to remove all preferences.

Third-party services used by the tools

  • Speed test: the browser exchanges test traffic with Cloudflare speed-test endpoints and may use CacheFly as a download fallback. Upload tests send generated test data to the configured upload endpoint.
  • IP and connection details: the page requests your public IP and approximate ISP/location from ipapi.co, ipwho.is, db-ip.com and ipify.org, trying providers in sequence until it has enough information.
  • DNS benchmark: when you run it, the browser sends DNS-over-HTTPS queries to the public resolver providers shown on the page. Queries use example.com and generated test names.
  • Page assets: Font Awesome icons are loaded from a public CDN. The layout utility CSS is served with this site.

These providers receive network requests from your browser and can see your public IP address. Their own privacy terms govern data they process. Fast Mode does not control their retention practices.

Affiliate links

Some product links are affiliate links. If you make a purchase after following one, Fast Mode may receive a commission at no additional cost to you. The link is labeled as sponsored where applicable. Following an affiliate link takes you to a third-party site.

Cookies and advertising

The current site code does not include an active advertising script or analytics tracker. If either is added later, this page should be updated to identify the relevant provider and its data practices.

Search verification

The page includes a Google Search Console verification meta tag. It is used to verify site ownership and does not itself collect visitor analytics.
